📊 Scoring System & Ranking
1️⃣
Match Result Points
3–0 win: +3 pts
3–1 win: +2 pts
3–2 win: +1 pt
Bigger win = more points
2️⃣
Game Difference
Base: Game margin (8–1 = +7)
Bonus: D1/D2 straight (2–0) = +5
D3: No bonus (excluded)
3️⃣
Singles Game Diff
Count S1 + S2 games
Used only if tied
3rd tiebreaker
